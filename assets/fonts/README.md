# Self-hosted fonts

These are the same Barlow Condensed and DM Sans families previously loaded through
Google Fonts. They are served locally so catalog/photo search does not request a
third-party stylesheet or font service. Both are distributed under the SIL Open
Font License 1.1; their original notices are included alongside the files.

Sources:

- https://github.com/google/fonts/tree/main/ofl/barlowcondensed
- https://github.com/google/fonts/tree/main/ofl/dmsans

Barlow Condensed uses the Medium, SemiBold, Bold and ExtraBold static files. DM Sans
uses the original variable `DMSans[opsz,wght].ttf` file, renamed to `DMSans.ttf`.
