# Catalog consistency review — 23 October 2026

All 2,665 records were checked for unique IANs, full-IAN consistency, impossible numeric values, contradictory power sources and attachment-type conflicts. Existing product URLs and the nine approved categories were preserved.

## Changes

- Updated 104 product records.
- Added or corrected 78 specification entries, including SDS-Plus/SDS-Max holders, square and hex drives, disc bores, spindle threads and B16 chuck mounts. Each new manual-based value has a per-IAN page reference.
- Completed mains power for 33 standalone chargers and corrected four contradictory power sources. A precision screwdriver using replaceable AAA cells now states its battery supply explicitly instead of claiming manual power.
- Corrected ten descriptions, including a 3/8-inch ratchet previously described as half-inch, impact drivers versus impact wrenches, hammer drill drivers and a diamond grinding cup wheel previously labeled as a cutting blade.
- Separated tightening torque from breakaway torque; the 600 Nm loosening rating is no longer presented as the generic tightening rating for two impact wrenches.
- Scoped a kit's stroke length to its reciprocating saw and removed an unscoped kit-wide torque value. A component manual was not used to assign a single model to the whole kit.
- Recovered five previously unknown printed model codes. The documented WWS model code was retained alongside the catalog model for two water-pump records.
- Harmonized two classifications using the main function of the actual product.

No duplicate IANs were found. Identical photo checks found one cross-category pair of generic gel knee pads; the classification was aligned without merging the distinct IAN records or copying manufacturer claims.

## Ongoing checks

The audit now rejects mismatched full IANs, zero power/diameter/capacity, a bore at least as large as its disc, conflicting manual/cordless or mains/petrol labels, and explicit square/hex attachment contradictions. Undocumented values remain allowed to be unknown. Combo holders with both a square drive and a hex socket are supported.

## Validation

The build, 22 tests and catalog audit passed. Browser verification covers the corrected pages in Italian and English at four viewport widths, including the torque labels, precision bits, charger supply, kit scope and the restored grinding-disc variant group.
